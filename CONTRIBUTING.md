# Contributing

Thank you for your interest in BetterChoice India.

This repository is published for **viewing and evaluation**; its code is not open for reuse (see
[LICENSE](LICENSE)), and **pull requests are not accepted** at this time.

Feedback is very welcome through [Issues](../../issues):

- **Wrong colour or reading:** use the *Wrong rating* template. Include the shopping app, the product name and a
  photo of the pack's nutrition table, if you can.
- **Bug:** steps to reproduce, the Android version and phone model, and what you expected.
- **Idea:** what problem it solves for a shopper.

Security issues: please follow [SECURITY.md](SECURITY.md) and do not open a public issue.
